
# WebDev-L1-LandingPage

## Project Overview
Nova Studio is a fictional creative digital brand landing page
created for the Oasis Infobyte Web Development & Designing internship.

## Technologies Used
- HTML5
- CSS3
- CSS Flexbox and Grid
- Responsive media queries

## Features
- Sticky navigation bar
- Hero section with call-to-action
- Features and About sections
- Contact section and footer
- Responsive desktop and mobile layouts
- Smooth scrolling navigation

## How to Run
1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open index.html using Live Server, or open it directly in
   a web browser.

## Screenshots
Add screenshots of the desktop and mobile layouts to the
screenshots folder.

## Learning Outcome
Practised HTML structure, CSS styling, responsive layouts,
navigation and page section design.
