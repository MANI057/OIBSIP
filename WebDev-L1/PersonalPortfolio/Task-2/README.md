
# Personal Portfolio Website

## Project Overview
A personal portfolio website created as part of the Oasis Infobyte Web Development & Designing internship.

## Technologies Used
- HTML5
- CSS3
- Flexbox
- Responsive Media Queries

## Features
- Home section
- About Me section
- Skills section
- Project cards
- Contact section
- Smooth scrolling
- Mobile responsive design

## How to Run
1. Open the project folder in VS Code.
2. Open index.html.
3. Run using Live Server.

## Learning Outcomes
Practised HTML page structure, CSS styling, navigation, layouts and responsive web design.
