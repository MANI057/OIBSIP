
Temperature Converter

Project Overview
A Temperature Converter web application developed as part of the Oasis Infobyte Web Development & Designing Internship (Level 1 - Task 3).

Technologies Used
- HTML5
- CSS3
- JavaScript

Features
- Convert Celsius to Fahrenheit and Kelvin.
- Convert Fahrenheit to Celsius and Kelvin.
- Convert Kelvin to Celsius and Fahrenheit.
- User input validation.
- Displays error messages for invalid temperatures.
- Prevents temperatures below absolute zero.
- Responsive user interface.

How to Run
1. Open the project folder in Visual Studio Code.
2. Open index.html.
3. Right-click and select Open with Live Server.
4. Enter a temperature.
5. Select the input unit.
6. Click the Convert button to view the results.

Project Structure
- index.html – Defines the application structure.
- style.css – Provides the design and responsive layout.
- script.js – Performs temperature conversion calculations.
- screenshots/ – Stores application screenshots.

Learning Outcomes
- Practised HTML page structure.
- Learned CSS styling and responsive design.
- Used JavaScript functions and conditional statements.
- Implemented input validation and temperature conversion formulas.
